# XR-Collab-Real V0.2 需求规范

## 1. 核心目标
实现 AR 引导下的精准室内拍摄，为 V0.3 的高质量 3D 重建提供可靠的基础数据。

## 2. 功能清单
- [ ] **AR 引导系统**：在 Vision Pro / 移动端 AR 空间中显示 3D 拍摄点位。
- [ ] **路径导航**：实时计算并显示从当前位置到下一个最佳拍摄点的路径。
- [ ] **智能触发**：当用户移动到指定点位并保持稳定时，自动触发拍照。
- [ ] **覆盖度校验**：实时分析已拍摄照片的重叠度，确保无死角覆盖。
- [ ] **环境反馈**：如果光线不足或遮挡严重，及时通过 AR UI 提醒用户。

## 3. API 规范 (V0.2)

### GET /api/v0.2/capture-session/start
初始化一个新的拍摄会话。
**返回**：
```json
{
  "sessionId": "string",
  "suggestedPath": [
    { "x": number, "y": number, "z": number, "heading": number }
  ]
}
```

### POST /api/v0.2/capture-session/{sessionId}/verify
上传并验证当前拍摄点的照片质量。
**请求**：Multipart Form Data (image + tracking data)
**返回**：
```json
{
  "status": "success | retry",
  "reason": "string (optional)",
  "nextPointIndex": number
}
```

## 4. 数据结构定义
```typescript
interface ARCapturePoint {
  id: string;
  position: Vector3;
  orientation: Quaternion;
  isCaptured: boolean;
  qualityScore: number;
}

interface CaptureSession {
  id: string;
  points: ARCapturePoint[];
  progress: number; // 0-100
  startTime: number;
}
```

## 5. 验收标准
1. AR 点位在空间中位置固定，漂移小于 5cm。
2. 环形路径引导顺滑，无明显延迟。
3. 拍摄点覆盖率达到 95% 以上方可完成会话。
