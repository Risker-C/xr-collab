## 快速入门

### 什么是建筑扫描功能？

XR Collab的建筑扫描功能允许您使用WebXR设备或移动设备（iOS/Android）对真实建筑空间进行3D扫描，生成高精度点云和网格模型，并在多人协作房间中实时共享。

### 支持的设备

- **Web端**: 支持WebXR的浏览器（Chrome、Edge、Firefox）
- **iOS**: iPhone 12及以上（支持LiDAR的设备效果更佳）
- **Android**: 支持ARCore的设备（Android 7.0+）

### 扫描流程概览

```
创建扫描会话 → 开始采集 → 实时预览 → 上传处理 → 查看结果 → 发布到房间
```

## Web端扫描

### 1. 进入扫描模式

1. 打开XR Collab应用
2. 加入或创建一个协作房间
3. 点击工具栏的"扫描"按钮
4. 选择"开始新扫描"

### 2. 配置扫描参数

```
扫描质量: 高/中/低
采集模式: 摄影测量/实时预览
启用深度: 是/否（如果设备支持）
```

**推荐设置**:
- 首次使用: 中等质量
- 小型房间: 高质量
- 大型场景: 中等质量 + 分区扫描

### 3. 开始采集

1. 点击"开始采集"按钮
2. 缓慢移动设备，保持稳定
3. 确保场景重叠度 ≥ 70%
4. 关注屏幕上的质量提示

**采集技巧**:
- 保持1.5-3米的扫描距离
- 避免快速移动（建议1-2秒/帧）
- 确保光照充足且均匀
- 避免拍摄反光表面

### 4. 实时预览

采集过程中，您可以看到：
- 当前采集帧数
- 覆盖区域预览（绿色=已覆盖）
- 质量评分（模糊度、重叠度）
- 预估完成时间

### 5. 完成采集

1. 确认覆盖所有目标区域
2. 点击"完成采集"
3. 系统自动上传数据
4. 等待后台处理（通常5-15分钟）

## 移动端扫描

### iOS扫描步骤

#### 1. 安装应用
```bash
# 通过TestFlight或App Store安装
```

#### 2. 启动扫描
```
打开应用 → 选择房间 → 点击"扫描" → 授权相机和传感器权限
```

#### 3. 扫描设置
- **高质量模式**: 适合小型精细场景（< 50㎡）
- **平衡模式**: 适合中型房间（50-200㎡）
- **快速模式**: 适合大型场景预览

#### 4. 采集指导
应用会实时显示：
- AR引导线（建议移动路径）
- 覆盖热力图
- 质量警告（模糊、曝光过度等）

### Android扫描步骤

与iOS类似，但需注意：
- 首次使用需下载ARCore服务
- 部分设备不支持深度采集
- 建议使用高端设备（骁龙8系列）

## 扫描结果查看

### 1. 查看扫描列表

```
我的扫描 → 选择扫描会话 → 查看详情
```

显示信息：
- 扫描时间和地点
- 处理状态（处理中/已完成/失败）
- 点云数量、网格面数
- 可用LOD级别

### 2. 3D预览

点击"预览"按钮：
- 旋转: 单指拖动
- 缩放: 双指捏合
- 平移: 双指拖动
- 切换LOD: 右上角下拉菜单

### 3. 下载模型

支持格式：
- **glTF/GLB**: 推荐，支持纹理和压缩
- **PLY**: 点云格式
- **OBJ**: 通用网格格式

```javascript
// 下载示例
scanAPI.download(scanId, {
  format: 'glb',
  lod: 1,
  includeTexture: true
});
```

## 协作扫描

### 多人同时扫描

1. 房间内多个用户可同时创建扫描会话
2. 每个用户的扫描进度实时同步
3. 完成后可合并多个扫描结果

### 实时预览共享

启用"共享预览"选项：
- 其他用户可实时看到您的扫描进度
- 显示为半透明点云覆盖
- 帮助团队协调扫描区域

### 扫描结果发布

```
选择扫描 → 点击"发布到房间" → 设置锚点位置 → 确认
```

发布后：
- 所有房间成员可查看
- 支持标注和测量
- 可导出为协作资产

## 常见问题

### Q: 扫描失败怎么办？
**A**: 检查以下几点：
1. 网络连接是否稳定
2. 采集帧数是否足够（建议 > 50帧）
3. 场景是否有足够纹理特征
4. 查看错误日志获取详细信息

### Q: 如何提高扫描质量？
**A**: 
- 增加采集帧数和重叠度
- 确保光照均匀
- 避免动态物体（人、车等）
- 使用高质量模式

### Q: 扫描数据存储在哪里？
**A**: 
- 原始数据: 云端对象存储（S3）
- 处理结果: CDN分发
- 本地缓存: 浏览器IndexedDB（可清理）

### Q: 支持离线扫描吗？
**A**: 
- 采集可离线进行
- 上传需要网络连接
- 支持断点续传

### Q: 扫描数据如何计费？
**A**: 
- 存储: 按GB/月计费
- 处理: 按扫描次数计费
- 下载: 按流量计费
- 详见定价页面
